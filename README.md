# Живая деревня

Локальный MVP автономных NPC: деревня XIII века живёт своей жизнью, а вокруг неё — живая экосистема (лес, река, звери, погода). Цель — чтобы **прожитый опыт реально влиял на решения персонажей**.

Основной цикл:

```text
Жизнь мира → событие → восприятие NPC → рефлексия → изменение памяти → последующие решения
```

**Код даёт факты и правила мира; модель определяет личный смысл опыта и предлагает изменения памяти.**

## Что умеет

- **Деревня**: дворы с жителями (роли: земледелец, лесоруб, рыбак, ткачиха, трактирщик), домочадцы, скот-особи, ульи.
- **Годовой цикл**: 4 сезона × 7 дней, посев → жатва → зима; оброк сеньору и десятина церкви; взаимопомощь, церковный сход.
- **Память и LLM** (опционально): у персонажей ядро, воспоминания, отношения, убеждения; DeepSeek — для рефлексии, диалога и выбора намерений.
- **Живая местность (карта-сетка)**: почва/гидро/флора, сукцессия леса (вырубка → молодняк → смешанный → зрелый), фауна (заяц/лиса/кабан) с хищник-жертва, погода, паводок.
- **Детерминизм**: тот же `seed` → тот же мир.

## Технологии

- Node 24, TypeScript, Fastify (API), `node:sqlite`, React 19 + Vite.
- Тесты: `node:test`.

## Запуск

```bash
npm install
npm run start          # бэкенд на http://127.0.0.1:3001
npm run dev:web        # фронтенд на http://localhost:5173 (прокси /api → 3001)
```

Откройте http://localhost:5173 — слева карта мира (зум, клик для осмотра клетки), справа легенда и сворачиваемые детали деревни. Кнопка «▶ Авто» запускает авто-продвижение.

### Настройка `.env` (только для LLM)

```bash
DEEPSEEK_API_KEY=sk-...
DEEPSEEK_BASE_URL=https://api.deepseek.com   # опционально
# DEEPSEEK_TLS_INSECURE=1                     # только для MITM-прокси/антивируса
```

Без ключа LLM-возможности молчат — деревня живёт на детерминированной логике.

## Команды

- `npm test` — тесты (детерминированные; guarded LLM-тесты — только с `RUN_LLM_TESTS=1`).
- `npm run typecheck` — проверка типов.
- `npm run build` — сборка фронтенда.

## Структура

| Путь | Что |
|---|---|
| `server/` | бэкенд: `world.ts` (деревня), `terrain.ts` (сетка/экосистема), `agent.ts` (LLM), `db.ts` (схема) |
| `web/` | фронтенд: `App.tsx`, `WorldMap.tsx` (карта) |
| `docs/` | решения (`DECISIONS.md`), статус (`STATUS.md`), историческая справка (`docs/reference/`) |
| `test/` | тесты |

База SQLite — в `data/village.db` (`data/` в `.gitignore`). Ключи API в исходники не класть.
