# Changelog

## v0.2.0 — хозяйство, экономика и годовой цикл (2026-10-01)

Вторая зафиксированная версия. К автономным NPC добавлена связная историческая экономика: двор кормит себя, сезонность, скот как живые особи.

### Хозяйство (этапы 1–6)

- **Надел**: огород (овощи), луг (сено), поле (зерно) у каждого двора.
- **Роль вторична**: зерно растят все дворы, земледелец лишь больше (правка №2).
- **Скот**: коровы/волы/птица — едят сено, дают молоко/яйца/навоз/тягу (правка №1).
- **Болезнь и энергия**: перегруз уводит энергию в минус, голод/болезнь бьют по здоровью, сон лечит.
- **Взаимопомощь**: голодный/больной получает еду от соседа с излишком, растёт доверие.
- **Выходной**: каждый 7-й день — отдых и восстановление.

### Годовой цикл (правка №3)

- 28 дней = 4 сезона (весна/лето/осень/зима).
- **Посев весной** (семена), **жатва осенью** («сам-три»: урожай = посев × 3 + навоз), **зима** — дефицит (огород/луг не плодоносят).
- Провал посева → нет урожая → оброк провален.

### Скот-особи (D-036)

- Каждая корова/вол/птица — отдельная особь со своим именем, здоровьем и возрастом.
- Возраст растёт и расходится; болезнь — индивидуально (схема v13).

### Просмотр через UI

- Сезон в шапке, панели «Скот (особи)» и «Наделы», здоровье жителей.

## v0.1.0 — локальный MVP (2026-10-01)

Первый зафиксированный срез. Локальный MVP «Живой деревни»: автономные NPC с wiki-памятью, рефлексией и реальной LLM-моделью.

### Что входит (этапы 0–9 + три приоритета из отчёта EVALUATION)

- **Документация**: `CONCEPT`, `ROADMAP`, `STATUS`, `DECISIONS` (D-001…D-035), `EVALUATION`, `MEMORY_MODEL`.
- **Каркас**: TypeScript, Fastify (сервер), React + Vite (UI), SQLite (встроенный `node:sqlite`).
- **Движок**: игровое время (4 фазы), действия, атомарное сохранение, журнал событий, детерминированный PRNG по seed.
- **Автономная жизнь**: 7 жителей, роли, расписание (работа/еда/сон), энергия, конечный урожай, обязательства с автоурегулированием.
- **Внешний мир**: торговец, внешние события, разделение факта и знания NPC, ложные слухи.
- **Wiki-память**: ядро/опыт/воспоминания/отношения/убеждения, атомарный протокол рефлексии (idempotency, stale-revision), ревизии.
- **Реальный LLM (DeepSeek)**: рефлексия (`deepseek-v4-pro`), выбор намерения и диалог (`deepseek-flash`), серверные метрики токенов/стоимости, лимиты (таймаут/повторы/параллельность).
- **Забывание и консолидация**: бюджеты, вытеснение, механическое и смысловое (моделью) сжатие, краткие следы знакомых.
- **Игровой MVP**: режимы игра/отладка, автозагрузка мира, ускорение, действие игрока.
- **Оценка качества**: отчёт `EVALUATION`, автономный выбор NPC в значимых узлах, A/B статической vs рефлексивной личности.
