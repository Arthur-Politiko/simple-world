# Местность и её масштаб (справка)

> Оценки для игровой модели. Историческая основа — Северо-Восточная Русь XIII–XIV вв., смешанная лесная зона. Числа округлены и задают **порядок величин**, а не точную статистику.
>
> **Сверено с** `docs/reference/пейзаж_деревня_13_век.txt` (панорама села Баженово и земельный баланс) — разделы «Площадь» и «Фауна» уточнены по этому источнику.

## 1. Масштаб поселения

| Показатель | Наш MVP | Целевой масштаб |
|---|---|---|
| Дворов | 4 | 10–12 (малая деревня) |
| Ртов | ~20 | ~50 |
| Голов скота (на деревню) | ~6–8 | ~25–40 |

Территория на ~50 человек: **~400–700 га (4–7 км²)**. Для нашего MVP — в ~3 раза меньше: **~130–230 га**.

## 2. Площадь земли (на 12 дворов ≈ 50 чел.)

| Угодье | Площадь | Зачем |
|---|---|---|
| Пашня (посевы + пар) | 70–100 га | зерно на еду/семена/оброк; половина под паром |
| Сенокосы (пойменные) | ~60 га | ~90 т сена на зиму скоту |
| Пастбища и выгоны | ~70 га | летний выпас ~20 коров, ~12 лошадей, ~40 овец |
| Усадьбы и огороды | ~2 га | 12 дворов с клетями, хлевами |
| Перелоги и подсеки | 30–50 га | резерв на будущие годы (обновление плодородия) |
| Лес | 100–200 га | дрова (~12 м³/двор/год), борти, охота, грибы |
| Речка/пойма/старица/болотина | 10–20 га | рыба, водопой, камыш |

**Итого ~350–450 га, реально 500–800 га (5–8 км²)** — круг радиусом 1.5–2 км от села. Лес — не один участок, а несколько (ближний + дубравы-редколесье + дальний «чернолесье»).

## 3. Локации и их ресурсы (истощаемые/восстанавливаемые)

| Локация | Ресурс | Запас | Прирост/год | Изъятие деревней/год |
|---|---|---|---|---|
| Лес | дрова | 300–500 возов | ~60–100 возов | 60–80 возов |
| Лес | строевое бревно | ограничено | ~5–10 лет на восстановление | редкое (постройка) |
| Лес | ягоды/грибы/орехи | сезонный | летом/осенью | сезонный сбор |
| Луг | сено | сезонный укос | ~1.5–2.5 т/га | 70–100 т/год (12 дворов) |
| Пастбище | трава (корм) | сезон | лето | выпас скота |
| Река | рыба | запас (тысячи) | нерест весной | вылов ≤ 30–40% запаса |
| Поле | зерно | уже в модели (урожай) | посев → жатва | — |

**Принцип:** каждое угодье имеет `запас` + `прирост/год`; изъятие деревни должно быть ≤ прироста, иначе истощение.

## 4. Флора (агрегаты, не отдельные растения)

- **Лес** (смешанный: ель/сосна/берёза/дуб/ольха): плотность ~200–400 деревьев/га; подрост и валежник.
- **Кустарник** (опушки, заросли): лещина (орехи), малина, черника, ива.
- **Луг/сенокос**: травостой ~2–3 т/га/год.
- **Пастбище**: общее, кормит ~10–20 голов скота в сезон.

Модель: «лес» = один агент с состоянием `{плотность, запас дров, ягоды}`, а не 500 деревьев.

## 5. Фауна (популяции, не особи)

По «пейзаж_деревня_13_век.txt» — плотности Среднего Поволжья XIII в. на округу села (~5–8 км²):

| Вид | На округу (~5–8 км²) | Модель |
|---|---|---|
| Кабан | 1–2 семьи, 8–15 голов | 1 популяция ~8–15 |
| Лось | 3–5 | 1 популяция ~3–5 |
| Медведь | 1–2 (в глухом лесу) | особь-«риск» для бортника |
| Рысь | 1–2 | 1 популяция |
| Лиса / куница | по опушкам и у дворов | 1–2 популяции |
| Заяц / белка / тетерев / глухарь / рябчик | в перелогах, на межах, в борах | по 1 популяции (десятки–сотни) |
| Волк | **стая 5–9 на 100–200 км²** (в 20–30× больше села) | **внешняя угроза, не резидент** |
| Рыба (река) | плотва/окунь/щука/язь; нерест весной | пул «рыба в реке» |

**Ключевое:** волк — **не резидент** (стая контролирует 100–200 км²), это внешняя угроза скоту (набеги), а не популяция внутри круга. Кабан — главная угроза посевам. Округа «сама себя страхует»: заяц/тетерев в котёл, шкуры/мех на обмен, кабан/лось — подспорье в неурожай.

## 6. Устойчивость (чтобы не истощить за год)

| Ресурс | Прирост | Устойчивое изъятие |
|---|---|---|
| Дрова | ~1–3 м³/га/год | ≤ 50–70% прироста |
| Сено | ~1.5–2.5 т/га/год | 1–2 укоса, не под корень |
| Рыба | нерест весной | ≤ 30–40% запаса |
| Дичь (заяц/птица) | ~2–4× в год | охота ≤ 30–40% популяции |
| Кабан/лось | медленно | охота редкая (праздничная) |

**Вывод:** при площади ~500 га и дисциплине «изъятие ≤ прироста» местность восстанавливается и не пустеет за год.

## 7. Принцип модели (связка с D-036/D-039)

- **Локация = агент-автомат**: состояние `{запас ресурсов, сезон, погода}` + переходы (день/ночь, сезон). Это «константа, которая меняется».
- **Флора = агрегат** («лес», «кустарник», «луг») — не отдельные растения.
- **Фауна = популяции** («стая зайцев») — не особи; каждая популяция — «недо-FSM» (декларативная запись, как `CREATURE_DEFS`).
- **Связка с деревней обязательна**: дрова/ягоды/рыба/дичь/сено — берутся деревней **из этих запасов**, иначе «объём без смысла».

## 8. Пространство (зацепки на будущее)

Сейчас пространство вводим **мягко**, без координат:

- У локаций есть **соседство** (лес — рядом с деревней; река — за полем; дальний лес — за рекой).
- У угодий есть **примерное расстояние** («в получасе ходьбы», «день пути»).
- Позже можно добавить: направление/координаты, движение персонажей, маршруты торговца.

Не вводим резко полную карту — только зацепки, чтобы потом расширить без переделки.

## Как пользоваться справкой

При введении «живой местности» сверяемся с этой таблицей:

1. У каждого угодья — `запас` и `прирост/год` из раздела 3.
2. Флора/фауна — агрегаты/популяции из разделов 4–5.
3. Проверяем устойчивость: `изъятие ≤ прирост` (раздел 6).
4. Для MVP (4 двора) все числа делим примерно на 3.
