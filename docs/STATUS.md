## Сделано

### Этапы 1–4

- Правовой уклад: деревня на земле сеньора, осенний оброк зерном к 20-му дню (решение D-023).
- Конечный урожай на поле (80) — еда и платёж конкурируют за зерно.
- Торговец: визит каждые 5 дней, ограниченные деньги (40) и товар (зерно 20, соль 10), покупка дров/рыбы/ткани.
- Внешние события: размытая дорога (день 8) отменяет визит торговца.
- Отделение факта (`facts`) от знания NPC (`knowledge`): знание только через источник (трактир), с флагом истинности.
- Ложный слух (день 9) остаётся убеждением и не меняет факты.
- Трактирщик (7-й житель) в трактире — источник получения новостей.
- API: `/trade`; состояние включает факты, знания и торговца.
- Базовые тесты симуляции и внешнего мира: 25 шт.

### Этап 5 — wiki-память и протокол изменений

- SQLite schema v5: additive migration с v4; старые записи `knowledge` сохраняются, а неизвестный исторический event provenance остаётся NULL.
- Добавлены wiki-сущности: ядро/текущее состояние с revision, recent/significant entries, отношения, убеждения, протокол предложений и история ревизий.
- Добавлена ссылка `knowledge.event_id` на событие передачи сведений. Ложный слух сохраняется как убеждение, не как факт.
- Добавлен атомарный API применения reflection proposal: валидация источников, диапазонов, лимита 32 отношений, stale revision, idempotency по proposalId + payload hash.
- API чтения JSON, экспорт Markdown, POST применения предложения.
- В интерфейсе добавлена панель Wiki по каждому жителю и ссылка на Markdown export.
- Детерминированный тестовый адаптер проверен на повторяемой сцене с ложным слухом.
- Реальный LLM API не подключён.

## Проблемы и ограничения

- Перераспределения еды нет: не-земледельцы голодают.
- Реализована миграция только v4→v5; более старые базы не поддерживаются автоматически.
- Старые записи knowledge мигрируют с `event_id=NULL`, потому что их исходное событие достоверно неизвестно.
- Wiki-память пока не используется симуляцией для выбора действий NPC; есть протокол записи/чтения и тестовый сценарий.
- Нет автоматического скользящего окна, консолидации, токен-бюджета и вытеснения памяти.
- Реальный LLM API не подключён.
- UI создан и прошёл production build, но ручное браузерное тестирование Wiki-панели нужно выполнить.
